# Portfolio Dashboard Visuals

These PNGs are preview images for GitHub and a LinkedIn project post.

1. `01_dashboard_overview.png` — KPI and performance overview.
2. `02_daily_sales_trend.png` — day-by-day delivered revenue across 2025.
3. `03_weekday_sales.png` — Monday-to-Sunday revenue comparison.
4. `04_category_performance.png` — category performance.
5. `05_regional_performance.png` — regional performance.
6. `06_top_products.png` — top 10 products by delivered revenue.

The live interactive dashboard is `../Interactive_Dashboard.html`. Open it in Chrome or Edge to use the Region, Category, Sales Channel, Order Status, Month, and Day of Week filters.

All visuals use the same synthetic practice dataset (600 orders, 2025). Profit is estimated using assumed margins, not audited business profit.
