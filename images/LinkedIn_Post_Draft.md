# LinkedIn project post draft

I’m sharing my E-Commerce Sales & Customer Analytics portfolio project.

I worked with a synthetic dataset of 600 e-commerce orders from 2025 and prepared an end-to-end analytics workflow using Excel, Python, SQL, and Power BI resources.

**What’s included**
- Interactive sales dashboard with filters for region, category, sales channel, order status, month, and day of week
- Daily and weekday sales trends
- Product, category, and regional performance analysis
- Python analysis, Jupyter Notebook, SQL queries, Excel dashboard, and Power BI DAX/build guide

**Important:** This is a practice project using synthetic data. Profit is estimated using assumed margins and is not real company financial data. The SQL queries and Power BI build guide are provided as project resources; a native Power BI `.pbix` file is not included.
