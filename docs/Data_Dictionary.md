# Data Dictionary

| Field | Meaning |
|---|---|
| Order_ID | Unique synthetic order identifier |
| Order_Date | Order date |
| Customer_ID | Synthetic customer identifier |
| City | City |
| Region | Sales region |
| Product | Product name |
| Category | Product category |
| Quantity | Units ordered |
| Unit_Price_INR | Unit price in INR |
| Discount_Rate | Discount rate |
| Revenue_INR | Revenue after discount |
| Profit_INR | Estimated profit based on assumed margins |
| Sales_Channel | Sales channel |
| Payment_Method | Payment method |
| Order_Status | Delivered, Returned, or Cancelled |

All data is synthetic practice data.
